# 并行分支会话

图谱中的已完成节点可以继续输入。原分支仍在运行或选择历史节点时，通过 Pi SDK 创建独立 session；选择空闲分支末尾时复用该分支。子分支可以继续分叉。点击节点只改变查看对象，「停止此分支」只停止对应 run。

默认同时运行上限为 8，可通过宿主环境变量 `PIX_MAX_PARALLEL_RUNS` 调整为 1–64。各分支使用同一个项目工作目录；会话历史隔离不等于工具对项目文件的修改隔离。

## 永久保存，不自动合并

- 主 session JSONL 只保存主分支。旁边的 `<session>.pix-tree/` 保存子 session、来源记录、完成检查点和输入意图。备份、移动会话时应一起保存这两部分。
- 每个分支拥有独立 Pi runtime、SessionManager 和 services；来源记录保存父分支、分叉节点和继承 ID 映射。多层分叉通过这些关联展示在同一张图中，公共历史只显示一次。
- 分支完成、主干空闲、关闭和重启都不会把分支内容写回主 session，也不会为了合并关闭或重建主 runtime。
- 分支存储只读取 `<session>.pix-tree/`，不迁移旧目录，也不读取或处理旧合并事务。
- session 面板仍列出顶层 session，内部子 session 不会成为数千个独立列表项。

## 显式导出

`exportJsonl` 和 `exportHtml` 导出整张图。点击导出时，同步捕获主分支与所有子分支的 SDK 完整记录，交给工作线程组合和校验；导出任务离开启动队列后，新的输入可以继续启动。正在流式生成、尚未形成完整 session 记录的内容不包含在此次快照内。

导出使用稳定 ID 去重、按父子依赖排序，并通过严格 JSONL 校验和 Pi SDK 的主分支/子分支上下文比较。结果写入独立临时目录，完成后原子发布到新目标文件；已有目标不被覆盖，主 session、分支源文件和游标不被修改。失败时清理临时输出，保留全部源数据，不产生缺少某个分支却被当作成功的导出。

JSONL 可作为独立 Pi tree 导入。HTML 复用 Pi 的 HTML 导出器，不启动 agent 或项目扩展。当前 SDK 未公开单独的 HTML 导出入口，版本相关的模块适配集中在 `pi-runtime.ts`，由实际导出测试验证。

未知扩展的 `custom` / `custom_message` 可能包含私有节点引用，暂不猜测重写；导出遇到这些内容会失败并保留来源，需对应格式的适配。正常分支保存和图谱展示不依赖导出成功。

## 恢复与数据边界

输入意图先持久化再启动 Pi。重启会恢复来源记录备份和准备阶段的分支文件，并展示未完成输入；不会自动重跑模型或工具。主干尾部半条 JSON 会在保留原始副本后恢复完整前缀；分支损坏时保留原文件并读取恢复副本或检查点。中间损坏、重复 ID 和缺失引用不会被静默忽略。

写入使用文件 fsync 和同目录替换。这不代表硬件故障或真实断电下的零丢失保证。各来源文件独立保留，使导出失败不会破坏正在运行的会话。不要同时让外部 Pi 进程写入同一个源文件。

## 图谱性能

- 共享投影和布局采用迭代遍历；布局结构不变时复用位置。后台缓存分支增量和聚合投影，运行状态变化不重新计算全部节点元数据。
- 渲染器把记录和投影作为不可变快照，避免为全部历史创建深层响应式代理；复用未变化的节点展示数据。
- Vue Flow 只挂载视口内的卡片，预设未测量节点的尺寸和连接位置，避免首次打开时先渲染全图。500 个节点以上，连线只呈现可见目标节点的入边；全图关系仍保存在数据中。
- 大图缩略图使用 Canvas，避免数千个 SVG 元素。节点悬浮只解析该回合，聊天选择只投影该节点的祖先路径。草稿文字、图片和提交状态由图谱持有，移出视口后不会因组件卸载而丢失。
- 大图只向 Vue Flow 提供视口节点及入边端点，避免其全列表父容器查找产生平方级开销。远距离节点定位直接跳转，避免缩放动画在途中临时展示整张图。
- 历史源文件仍会在打开时读取；源文件数量、复制的祖先上下文和 IPC 快照大小仍影响首次加载和内存占用。没有宣称无限节点下性能不变。

## 验证

`test/graph-runtime.test.ts` 使用真实 Pi SDK 和本地模型，覆盖并行、嵌套分叉、空闲分支复用、独立停止、请求去重、运行中 JSONL/HTML 导出、无自动合并和重启稳定 ID。`test/graph-files.test.ts` 覆盖所有权锁、缺失依赖、损坏来源和元数据恢复。

编译测试后运行 `node scripts/graph-benchmark.mjs` 可获得投影/布局基准。使用 `PIX_GUI_BRANCHES=1000 node scripts/gui-parallel-fixture.mjs` 启动隔离的真实 Electron 测试环境：1000 个实际子 session，每个 5 回合，共 5001 个节点，所有模型调用仅连接本地测试服务。

启动上述窗口后运行 `node scripts/gui-tree-check.mjs`。它通过真实鼠标和键盘验证视口裁剪、跨分支定位、缩略图、缩放和草稿卸载后的保留，将截图和性能报告写入隔离测试目录。2026-09-06 Windows 本机实测：初始 5 个节点/11 条连线，交互期间最多 6 个节点，帧间隔 P95 16 ms，无超过 50 ms 的主线程长任务。测试覆盖 5001 个节点，不是对所有硬件和任意规模的保证；报告中的 reloadMs 是渲染器重载时间，不含首次打开源文件的成本。
